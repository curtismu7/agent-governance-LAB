# agent-governance-LAB

Demo-tier standalone app: Ping AI Platform Agents release claims (deck slides 18, 19, 21, 35, 45 and 58, release 2026-11-02): a cross-cloud inventory across thirteen sources, a permission review with a five-level score, custodians with administrator approval before any action runs, remediation, a safe sync (gone vs the provider did not answer), AgentCore gateway governance and private-network discovery. Simulated. **Every product claim is "Ping release claim, UNVERIFIED on our tenant"** (banner on every tab, presenter mode too).

- Run: `./scripts/run.sh` (http://localhost:7300). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest against the real Express app; scripts). Preflight `npm run doctor`. Reset `npm run reset`. Docker: `HOST_PORT=7300 docker compose up --build -d`. Node 26 only.
- Modes: **Mock** (default) = tables (`server/src/mockTable.json`, generated by `npm run mock-table` from eight scripted scenarios run through the engine; a doctor check and a test fail on drift; read-only, every write is 409). **Live** = the real engine on the visitor's own actions. Both loopback-only, zero outbound (netguard + a test).
- Core: `engine.js` (state machine: provider world, inventory, safe sync, proposals propose/approve/execute, succession, certification campaign, private network, snapshot; one Engine per workspace and vertical, deterministic, no I/O, no clock), `findings.js` (the lab's 13 findings and scoring), `gateway.js` (gateways, scorecard, the nine newly added metadata blobs (the schema has 30 fields; 21 not modelled), actions), `catalog.js` (13 sources, scopes, seeded agents), `actions.js` (the one dispatch used by the API, the scenarios and the tests), `scenarios.js` (+ Mock table builder), `credentials.js` + `mask.js`, `service.js`, `app.js`. Web: `useLab` hook (Mock and Live give one state shape, stale answers dropped), eight tabs.
- Rules that bite: the deck's numbers (13 sources, 46 findings, 5 levels) are the deck's, the lab's 13 findings and scoring are its own and labelled; the deck says quarantine on nine but names seven, the other two are not named, so the lab models seven (Agent Builder and Foundry refuse quarantine); the slide 45 safe-sync line is cut off (lab reading); Risk Scoring is Planned on slide 21 while slide 45 describes a score (shown, not resolved); anything Roadmap (Q4 2026) or Planned carries its tag and "no behaviour is claimed"; certification and succession are "described in the deck, availability not stated"; credential-shaped and personal-looking values the visitor types are masked in every answer, state and log (a heuristic: not every secret has a recognisable shape; `echo.test.js` types every shape everywhere; `hostile-paths.test.js` sweeps token-shaped URL paths and workspace ids); unknown keys are refused without naming them; every user value used as a key is type-checked; refusals keep their honest HTTP status (no refusalsAs200); writes are synchronous per engine, caps refuse whole requests; the gateway JSON shapes are lab-invented ("the schema gives only the field name"); the gateway app is always "P1 Privilege Agent App"; ports 7300-7349; UI: shared `web/src/styles/standalone-ui.css` vendored byte-for-byte, app CSS tokens only (`bash ~/Development/AI-DEMO-Standalone/scripts/check-css.sh .`).
- Settings: one shared file `~/Development/.env` (mode 600, `STANDALONE_ENV` overrides), parsed with `util.parseEnv` in `server/src/settings.js`; this lab takes only `AGL_LAB_MODE`, never a bare MODE.
- Run check-drift, check-css and conformance by hand. SE k8s build deferred (owner, 2026-10-31); no k8s manifests. Catalog id D105 (assigned 2026-10-31, owner delegated the choice; not yet recorded in the standalone plan).
